# 上野裕太郎｜Yutaro UENO — Personal Site

理論社会学／AIガバナンスをテーマとする個人サイト。トップページ上部の固定ナビから各セクションへ遷移します。

## 構成

- **About me** — 自己紹介
- **Bio** — 経歴
- **Research** — 研究テーマ
- **Thought** — [Substack（外部）](https://yutaro0518.substack.com/t/log)
- **Activities** — 所属・活動
- **Human Research Collective** — [Substack（外部）](https://humanresearchcollective.substack.com/)

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体 |
| `style.css` | デザイン |
| `script.js` | モバイルメニュー等 |
| `assets/` | 画像等 |

## ローカルで確認

`index.html` をブラウザで開く、または簡易サーバーで：

```bash
python3 -m http.server 8000
# http://localhost:8000
```
